# LEARNUP roadmap

## Milestone 0 — Product foundation
- [x] GitHub repository initialized
- [x] Premium responsive UI foundation and brand colors
- [x] Dashboard, library, review plan, quiz feedback and progress screens
- [x] Unit/E2E test scaffolding
- [ ] Run checks in a real workspace and resolve issues
- [ ] Cloudflare resources and deploy pipeline

## Milestone 1 — Real accounts and persistence
- Registration/login/logout, protected session, profile
- D1 migrations and ownership-safe CRUD
- Courses, chapters, settings, data export/deletion

## Milestone 2 — Course ingestion
- PDF upload and text extraction
- Camera/photo import, page cleanup and OCR
- Background jobs, retries, processing status
- Chapter/concept structure and source references

## Milestone 3 — Study content
- Short summaries, key points, definitions, formulas and flashcards
- Quiz generation by chapter, number of questions and difficulty
- Quality/grounding checks, ambiguity and duplicate prevention
- Detailed but concise corrections and misconception diagnosis

## Milestone 4 — Learning engine
- Attempts and answer analytics
- Mastery by concept/chapter
- Spaced-repetition scheduling
- Adaptive daily plan

## Milestone 5 — Exam mode and audio
- Timed exam simulation, detailed report and review plan
- Readiness estimate with confidence and caveats
- Audio summaries and oral practice

## Milestone 6 — Beta readiness
- Comprehensive E2E, accessibility and performance audits
- Privacy, security, abuse and rate-limit review
- Monitoring and crash/error tracking
- Android/iOS packaging, store assets and release checklist

## Milestone 7 — Growth
- Shareable study sets and groups
- Teacher/school features
- Subscription entitlements
- Moderated community resource library
